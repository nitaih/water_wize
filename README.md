# WaterWize 💧

WaterWize is a full-stack infrastructure monitoring and mapping application designed to track and manage agricultural water pipelines and network nodes.

## Features
- **Interactive Map:** Built with React, Vite, and Mapbox GL JS to visualize water network infrastructure in real-time.
- **Backend API:** Node.js & Express server handling pipeline data retrieval and spatial data.
- **Database & ORM:** Neon PostgreSQL managed via Prisma ORM.
- **Automated Testing:** Comprehensive unit and integration test suite using Jest and Supertest (achieving >85% code coverage).

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS / CSS, Mapbox GL JS, react-map-gl
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (Neon), Prisma ORM
- **Testing:** Jest, Supertest
